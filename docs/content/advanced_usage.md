# DigiMicPy recipes

These pages show calculations that can be performed with DigiMicPy's public
parameter objects and solver outputs:

- {doc}`coalescence` combines compatible parameter objects and parental states;
- {doc}`cue` calculates carbon-use-efficiency summaries; and
- {doc}`resource_flux` calculates uptake, retention, leakage, and maintenance
  fluxes.

The calculations are explicit recipes, not dedicated `digimicpy` helper
functions. Each page links to the platform-owned workflow for scientific
assumptions, interpretation, and reporting guidance.
